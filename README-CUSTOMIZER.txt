لوحة التحكم:
1) افتح customizer.html في المتصفح.
2) عدّل الألوان، أحجام الخطوط، نسبة صور الخدمات، الحواف، المسافات، وموضع كل صورة.
3) اضغط تحميل الإعدادات.
4) سيُحمّل ملف custom-settings.css.
5) ضع custom-settings.css بجوار index.html ثم ارفعه إلى GitHub Pages.

ملاحظة: لوحة التحكم لا تكتب داخل GitHub مباشرة؛ المتصفح لا يملك صلاحية تعديل ملفات المستودع. هي مولّد إعدادات بصري آمن.
